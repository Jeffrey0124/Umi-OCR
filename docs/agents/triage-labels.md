# Triage 标签

工程技能使用五个标准的 Triage 角色。本文件将这些角色映射到本仓库实际使用的问题标签。

| mattpocock/skills 中的标签 | 本仓库中的标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 维护者需要评估此问题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可以交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理此问题 |

当技能提到某个角色时，使用对应的标签字符串。
