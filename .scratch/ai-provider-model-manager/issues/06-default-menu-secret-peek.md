# 默认配置右键菜单、置顶与按住查看密钥

Status: ready-for-human

## 行为

- 移除卡片上常驻的“设为默认”。右键启用的非默认配置可打开菜单；默认项和禁用项不显示该菜单。保留测试、编辑、复制、启停、删除的直接操作。
- 支持键盘聚焦卡片，通过菜单键或 Shift+F10 打开同一菜单。
- 当前启用的默认配置在列表首位展示，其他配置保持已有顺序。保存的配置 ID、页面选择和默认持久化逻辑沿用现有机制。
- 删除“显示密钥”复选框；输入框右侧使用小眼睛，按住鼠标或空格显示，松开隐藏。鼠标移出按钮、切换焦点、隐藏窗口、切换服务商和关闭弹窗时遮挡。
- 参考用户提供的 [Uiverse 眼睛组件](https://uiverse.io/catraco/moody-mole-16) 的眼睛/斜线状态，自行绘制 SVG 并使用原生 Qt 按钮实现按住行为。深浅色沿用主题。
- 本轮软件、安装器和产物版本同步为 2.1.8。

## 验证

- Qt 窗口浅深主题、紧凑尺寸和模型浮层预览在 `../previews-v2.1.8/`；测试使用临时配置与假密钥。
