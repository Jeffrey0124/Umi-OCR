# 内置姚记服务商、模型下拉框和版本递增

Status: ready-for-human

## 范围

- 内置服务商 `yaoji`，显示名称为姚记「梅花工作室」，默认地址为 `https://llm-proxy.yuwan-game.com/v1`，复用 OpenAI 兼容协议及 `/models` 拉取。
- 首次安装此内置项时优先沿用同地址的已保存配置，保留稳定 ID、密钥、模型和网络覆盖；一次性设为全局默认。记录 `installedBuiltins`，尊重后续用户切换、禁用、删除。
- 模型输入框内置展开箭头，右侧为刷新图标；列表使用独立搜索浮层，支持键盘选择、当前模型标记及底部手动添加。宽度与输入框一致，根据窗口空间向上或向下展开，保持固定底栏布局。
- 软件与安装脚本同步从 2.1.5 升至 2.1.6，并将每轮改动 patch 加 1 的规则写入 AGENTS.md。
