# AI 服务商与模型配置管理

Status: ready-for-human

## 目标

使用配置列表和分区编辑弹窗取代逐家展开的 API 字段；支持同服务商多套配置，以及第三方接口模型拉取、搜索和手填。

## 行为

- 管理窗口提供添加、编辑、设为默认、测试连接、复制、启停、删除。编辑草稿取消不落盘。
- 常用服务商优先，其余可搜索。全部现有服务商保留。
- 编辑区分基本信息、服务商与接口、模型、折叠高级设置；密钥默认遮挡，兼容密钥池。
- “设为默认”仅在启用的非默认卡片的右键菜单中显示，也可使用菜单键或 Shift+F10；默认卡片自动置顶，其余卡片保持原顺序。
- API 密钥使用输入框内小眼睛，按住显示、松开隐藏；鼠标移出、失去焦点、隐藏窗口和关闭编辑器均会遮挡。
- 模型请求使用草稿地址和密钥。兼容接口读取 `/models`，Gemini 支持分页，Ollama 使用 `/api/tags`。不推断或过滤视觉能力；无列表、空列表、失败均可手填。
- 请求异步执行，唯一请求 ID 防止旧结果覆盖新表单，关闭后忽略结果。
- 测试使用内置测试文字图片进行实际 OCR，与模型列表可用状态分开。
- 2.1.6 内置姚记「梅花工作室」，首次升级设为默认并复用同地址的已存密钥、模型和稳定 ID；以 `installedBuiltins` 记录一次性安装，后续不覆盖用户选择。模型下拉框采用独立搜索浮层，包含当前选择标记、底部添加和右侧刷新图标。
- 共享提示词、检测器、并发设置通过折叠展示分组，不改变旧设置键。

## 存储与生效

- `ocr.AIOCR.a_profiles` 存放 JSON 字符串：`version`、`activeId`、`profiles`。
- 配置包含稳定 `id`、`name`、`provider`、`enabled`、`api_base`、`api_key`、`model`，以及可继承的 `timeout`、`proxy_url`。
- 仅首次迁移当前服务商和用户填写过的其他服务商，旧键保留；默认配置同步对应旧字段。
- 页面 `a_l_profile` 默认跟随全局；旧 `a_l_provider` 首次读取后迁移并清空。
- 页面配置失效时回退全局并提示；默认配置被禁用或删除后清空默认。
- 每组任务在提交时固定有效配置，轮询队列不会互相覆盖。文档在提交时固定配置，所有页面继承同一快照。保存更新新任务的配置快照，当前队列不变；引擎在 OCR、文档的活动及暂停队列全部清空后重载。
